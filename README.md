## Getting Started

1. Clone this repository: `git clone https://github.com/thefoundryroom/thefoundryroom-website.git`
2. Open `index.html` in your browser to view the website
3. Customize content as needed

## Deployment with GitHub Pages

1. Go to repository **Settings** → **Pages**
2. Set source to `main` branch
3. Your site will be live at `https://thefoundryroom.github.io/thefoundryroom-website`

## Connect Your Custom Domain

To connect `thefoundryroom.in` to this site:

### Step 1: GitHub Setup
- A CNAME file is already added to the repository

### Step 2: Update GoDaddy DNS Records

Update these records in your GoDaddy DNS settings:

| Type | Name | Data |
|------|------|------|
| A | @ | 185.199.108.153 |
| CNAME | www | thefoundryroom.github.io |

## Customization Guide

### Edit Content
- Open `index.html` and modify text in each section
- Change colors in `css/styles.css`
- Add your logo, images, etc.

### Add New Sections
- Copy a section div from `index.html`
- Add corresponding CSS styling to `styles.css`
